# User Stories for Domain: NetBeans

## [US-000009] NetBeans Module
**As a** Developer,
**I want** to use Viber as a NetBeans module,
**So that** I can integrate conversation capabilities into NetBeans-based applications. (Post-MVP — implement after the pure JavaFX MVP is complete.)

### Technical Context & Constraints
* **Target System**: NetBeans Module based on ViberFX
* **Toolchain / Rules**: Java, JavaFX, Maven per `uzz/specs/development-framework.md`; NetBeans Module conventions; built on top of ViberFX

### Acceptance Criteria
```gherkin
Scenario: Install and load the NetBeans module
  Given the ViberNB NetBeans module is available
  When I install the module into a NetBeans application
  Then the module loads without errors
  and the Viber functionality is available within the NetBeans environment

Scenario: Use Viber within a NetBeans host application
  Given the ViberNB module is installed and loaded
  When I invoke the Viber functionality from within NetBeans
  Then the ViberFX UI is displayed and functional
  and Conversations can be created and interacted with

Scenario: NetBeans module integrates with ViberFX
  Given the ViberNB module is installed
  When I use Viber features within NetBeans
  Then the module leverages the existing ViberFX component
  and no duplicate UI logic is introduced
```
