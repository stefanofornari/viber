# User Stories for Domain: JavaFX UI

## [US-000004] JavaFX Conversation Control
**As a** Developer,
**I want** a JavaFX control to render and interact with a Conversation,
**So that** I can build rich desktop conversation user interfaces.

### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `uzz/specs/development-framework.md`; FXML descriptors whenever possible; UI construction separate from business logic per `uzz/specs/coding-standard.md`

### Acceptance Criteria
```gherkin
Scenario: Display a Conversation in a JavaFX control
  Given a JavaFX ConversationView control is available
  and a Conversation containing Chats and Messages is provided
  When I set the Conversation on the control
  Then the control renders all Chats and Messages visually
  and the Chats appear in order from left to right

Scenario: Messages within a Chat render top to bottom
  Given a Conversation with one Chat containing multiple Messages
  When the Conversation is displayed in the control
  Then the Messages appear top to bottom within the Chat

Scenario: Different Message types have distinct visual representation
  Given a Conversation containing Messages of different types
  When the Conversation is displayed in the control
  Then each Message type is visually distinguishable

Scenario: Empty Conversation renders gracefully
  Given a Conversation with no Chats
  When the Conversation is displayed in the control
  Then the control renders a valid empty state without errors
```
