# User Stories for Domain: CLI

## [US-000006] CLI Interface
**As a** Developer,
**I want** a terminal/CLI interface for Viber,
**So that** I can interact with conversations from the command line.

### Technical Context & Constraints
* **Target System**: Terminal application
* **Toolchain / Rules**: Java per `uzz/specs/development-framework.md`; TDD workflow per `uzz/specs/development-framework.md`

### Acceptance Criteria
```gherkin
Scenario: Start a conversation from the CLI
  Given VibeChatCLI is available
  When I start the CLI and provide an initial prompt
  Then the Conversation is created
  and the initial prompt appears as the first Message

Scenario: Continue an existing conversation from the CLI
  Given a persisted Conversation exists
  When I start VibeChatCLI and load the existing Conversation
  Then the CLI displays the existing Chats and Messages
  and I can continue the conversation

Scenario: Exit the CLI gracefully
  Given VibeChatCLI is running
  When I issue an exit command
  Then the CLI terminates cleanly
  and any unsaved state is handled appropriately
```
