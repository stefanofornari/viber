# User Stories for Domain: Text Renderer

## [US-000003] Text-based Conversation Rendering
**As a** Developer,
**I want** to render a Conversation as formatted text,
**So that** I can display conversations in any text-based context.

### Technical Context & Constraints
* **Target System**: Java library
* **Toolchain / Rules**: Follow Java conventions from `uzz/specs/coding-standard.md`; reusable rendering logic independent of any specific UI framework

### Acceptance Criteria
```gherkin
Scenario: Render a Conversation with one Chat as text
  Given a Conversation containing one Chat with two Messages
  When I render the Conversation to text
  Then the output contains both Messages in order
  and the output is valid readable text

Scenario: Render a Conversation with multiple Chats as text
  Given a Conversation containing two Chats
  When I render the Conversation to text
  Then the Chats are visually separated in the output
  and Messages within each Chat appear in order

Scenario: Different Message types render distinctly
  Given a Conversation containing Messages of type prompt, reply, and thought
  When I render the Conversation to text
  Then each Message type is visually distinguishable in the output

Scenario: Render an empty Conversation
  Given a Conversation with no Chats
  When I render the Conversation to text
  Then the output is a valid representation indicating an empty conversation
```
