# User Stories for Domain: JavaFX UI

## [US-000020] New Chat GUI Action
**As a** user,
**I want** to start a new chat from the GUI,
**So that** I can organize different topics of conversation.

### Technical Context & Constraints
* **Target System**: Standalone JavaFX desktop application
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `uzz/specs/development-framework.md`; FXML descriptors whenever possible; UI construction separate from business logic per `uzz/specs/coding-standard.md`
* **Prerequisite**: `US-000018` (ViberFX Standalone Application Entry Point) is complete

### Acceptance Criteria
```gherkin
Scenario: New Chat button is visible in the main window
  Given the ViberFX standalone application is running
  When I inspect the main window
  Then a "New Chat" button is visible

Scenario: New Chat creates a new chat tab
  Given the ViberFX standalone application is running
  and a Conversation with one Chat exists
  When I click the New Chat button
  Then a new Chat is created and added to the Conversation
  and the new Chat becomes the active chat
  and the conversation view displays the new chat tab

Scenario: New Chat is ready for input
  Given the ViberFX standalone application is running
  and I have created a new Chat
  When the new Chat is created
  Then the input area is focused and ready for the user to type a prompt

Scenario: Conversation state persists after New Chat
  Given the ViberFX standalone application is running
  and a Conversation with two Chats exists
  When I click the New Chat button
  Then both existing Chats remain in the Conversation
  and the new Chat is appended after them
```
