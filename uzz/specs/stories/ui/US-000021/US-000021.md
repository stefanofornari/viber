# User Stories for Domain: JavaFX UI

## [US-000021] Actor Selection Menu
**As a** user,
**I want** to switch the active actor from a menu in the GUI,
**So that** I can choose between FXActor and LangChain4jActor depending on my needs.

### Technical Context & Constraints
* **Target System**: Standalone JavaFX desktop application
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `uzz/specs/development-framework.md`; FXML descriptors whenever possible; UI construction separate from business logic per `uzz/specs/coding-standard.md`
* **Prerequisite**: `US-000018` (ViberFX Standalone Application Entry Point) is complete; `US-000008` (LangChain4j Actor) is complete
* **Default Actor**: FXActor is the default on startup

### Acceptance Criteria
```gherkin
Scenario: Actor menu is visible in the main window
  Given the ViberFX standalone application is running
  When I inspect the main window
  Then a menu bar is visible with an "Actor" menu

Scenario: Actor menu contains FXActor and LangChain4j Actor options
  Given the ViberFX standalone application is running
  When I open the Actor menu
  Then the menu contains "FXActor" and "LangChain4j Actor" options

Scenario: FXActor is selected by default on startup
  Given the ViberFX standalone application has just started
  When I open the Actor menu
  Then "FXActor" is checked or highlighted as the active actor

Scenario: Switching to LangChain4jActor changes prompt handling
  Given the ViberFX standalone application is running with FXActor active
  When I select "LangChain4j Actor" from the Actor menu
  Then the active actor switches to LangChain4jActor
  and subsequent prompts are dispatched to the LangChain4j model

Scenario: Switching back to FXActor reverts prompt handling
  Given the ViberFX standalone application is running with LangChain4jActor active
  When I select "FXActor" from the Actor menu
  Then the active actor switches to FXActor
  and subsequent prompts are handled by FXActor
```
