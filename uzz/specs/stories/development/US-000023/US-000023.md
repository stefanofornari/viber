# User Stories for Domain: Development

## [US-000023] Embeddable JavaFX Component via FXML
**As a** Developer,
**I want** to embed the ViberFX component directly in an FXML file,
**So that** I can declaratively compose the conversation UI alongside other JavaFX controls in my host application layout.

### Technical Context & Constraints
* **Target System**: Host JavaFX desktop application
* **Toolchain / Rules**: JavaFX, FXML, CommonsFX, AtlantaFX per `uzz/specs/development-framework.md`; FXML descriptors whenever possible per `uzz/specs/development-framework.md`; reusable embeddable UI parts per `uzz/specs/coding-standard.md`
* **Dependency**: Builds on US-000005 (Embeddable JavaFX Component)

### Acceptance Criteria
```gherkin
Scenario: Embed ViberFX component declaratively in FXML
  Given a host JavaFX application using FXML for its layout
  and a ViberFX embeddable component is available
  When the FXML includes a <GUIRenderer fx:id="conversation" /> element
  Then the FXMLLoader instantiates the component and adds it to the scene graph
  And the component is accessible via the fx:id reference

Scenario: Configure embedded component from controller
  Given an FXML file with a <GUIRenderer fx:id="conversation" /> element
  When the host application controller sets a Conversation on the conversation node
  Then the component displays the provided Conversation

Scenario: Component participates in FXML lifecycle
  Given an FXML file with a <GUIRenderer fx:id="conversation" /> element
  When the FXMLLoader finishes loading the FXML
  Then the component initialize() lifecycle method has been invoked
  And the component is ready to render
```
