# User Stories for Domain: Actor

## [US-000026] JavaFX Human-in-the-Middle Confirmation
**As a** User,
**I want** the JavaFX GUI to show a confirmation dialog before executing READWRITE or UNKNOWN tools when in INTERACTIVE mode,
**So that** I can visually review and approve potentially destructive filesystem operations.

### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `uzz/specs/development-framework.md`; UI construction separate from business logic per `uzz/specs/coding-standard.md`
* **Dependency**: Builds on US-000024 (Interaction Mode and Tool Policy Enforcement)

### Acceptance Criteria
```gherkin
Scenario: INTERACTIVE mode shows confirmation dialog for READWRITE tools in GUI
  Given the application is running in GUI mode
  and InteractionMode is INTERACTIVE
  When the LLM invokes a READWRITE tool
  Then a confirmation dialog appears showing the tool name and arguments
  and the dialog has OK and Cancel buttons

Scenario: User approves READWRITE tool execution in GUI
  Given a tool confirmation dialog is shown in the GUI
  When the user clicks OK
  Then the tool is executed
  and the result is returned to the LLM

Scenario: User denies READWRITE tool execution in GUI
  Given a tool confirmation dialog is shown in the GUI
  When the user clicks Cancel
  Then the tool is not executed
  and a denial message is returned to the LLM

Scenario: ASK mode blocks tool execution in GUI
  Given the application is running in GUI mode
  and InteractionMode is ASK
  When the LLM invokes any tool
  Then no tool is executed
  and a message indicating tools are disabled is returned

Scenario: AGENT mode executes tools without confirmation in GUI
  Given the application is running in GUI mode
  and InteractionMode is AGENT
  When the LLM invokes any tool
  Then the tool executes immediately without showing a dialog

Scenario: READONLY tools execute without confirmation in INTERACTIVE mode
  Given the application is running in GUI mode
  and InteractionMode is INTERACTIVE
  When the LLM invokes a READONLY tool
  Then the tool executes immediately without showing a dialog
```

### Implementation Notes
- The confirmation dialog is a modal JavaFX `Alert` or custom dialog showing the tool name, arguments, and OK/Cancel buttons.
- The dialog is shown on the JavaFX Application Thread and blocks the tool execution callback until the user responds.
- The user's choice is converted to a boolean and fed into the `HumanInTheMiddleWrapper`'s approval function.
- The dialog must not block the main UI thread's responsiveness; use `showAndWait()` on a modal dialog.
