# User Stories for Domain: viber

## [US-000007] Hello World Viber
**As a** Developer,
**I want** to start a new session with a goal oriented viber to render "Hello <name>"
where <name> is requested as input on the stdin
**So that** I experience an end-to-end conversation on the terminal

### Technical Context & Constraints
* **Target System**: Terminal
* **Toolchain / Rules**: Java per `uzz/specs/development-framework.md`; TDD workflow per `uzz/specs/development-framework.md`

### Acceptance Criteria
```gherkin
Scenario: Start a Viber session
  Given an a viber is a HelloWorldViber that renders a conversation on the stdout,
  When a viber.start() is called
  Then the following conversation is rendered on stdout:
    - system message: instructions for the actor
    - conversation
      - chat
        - message: greet me by my name
        - tool execution message: ask for the name
        - tool response message: the name read from stdin
        - message: hello <name>
```
