# User Stories for Domain: Actor

## [US-000027] FileSystemTools Unrestricted Execution
**As a** LLM,
**I want** to execute filesystem primitives such as read, write, list, search, create, and delete as tools without automatic policy restrictions,
**So that** I can freely interact with the project's files when operating in AGENT mode.

### Technical Context & Constraints
* **Target System**: Java application using LangChain4j actors
* **Toolchain / Rules**: Java, Maven per `uzz/specs/development-framework.md`; TDD workflow per `uzz/specs/development-framework.md`

### Acceptance Criteria
```gherkin
Scenario: Filesystem tools are exposed to the LLM in AGENT mode
  Given InteractionMode is AGENT
  and the actor is configured with filesystem tools
  When the LLM invokes a filesystem tool
  Then the tool executes directly without confirmation

Scenario: READONLY filesystem tools execute without policy checks in AGENT mode
  Given InteractionMode is AGENT
  and the actor is configured with filesystem tools
  When the LLM invokes readFile, findFiles, searchInFile, or listFilesInDirectory
  Then the tool executes without confirmation

Scenario: READWRITE filesystem tools execute without policy checks in AGENT mode
  Given InteractionMode is AGENT
  and the actor is configured with filesystem tools
  When the LLM invokes createFile, deleteFile, createDirectory, or deleteDirectory
  Then the tool executes directly without confirmation

Scenario: Filesystem tools are confined to the configured basedir
  Given filesystem tools are initialized with a project basedir
  When the LLM invokes any tool with a path outside basedir
  Then the tool rejects the path with an error
  and no filesystem operation is performed

Scenario: Tool execution results are rendered in the conversation
  Given the actor is configured with filesystem tools
  When the LLM invokes a tool
  Then a ToolExecutionRequestMessage is appended to the chat
  and a ToolExecutionResponseMessage with the result is appended afterward
```

### Implementation Notes
- `LangChain4jActor` accepts filesystem tools and makes them available to the LLM.
- In AGENT mode, all tools execute directly without policy enforcement or confirmation.
- Filesystem tools' basedir confinement via `checkPath()` operates unchanged.
- Tool request/response messages are appended to the conversation through the actor's streaming callback.
