# User Stories for Domain: Persistence

## [US-000002] Model Persistence
**As a** Developer,
**I want** to save and load Conversation models to/from persistent storage,
**So that** conversations can be resumed across application restarts.

### Technical Context & Constraints
* **Target System**: Java library
* **Toolchain / Rules**: Follow Java conventions from `uzz/specs/coding-standard.md`; TDD workflow per `uzz/specs/development-framework.md`

### Acceptance Criteria
```gherkin
Scenario: Save a Conversation to storage
  Given a Conversation with at least one Chat and Message
  When I persist the Conversation to storage
  Then the persisted data contains all Chats and Messages
  and the Conversation can be reconstructed from the persisted data

Scenario: Load a Conversation from storage
  Given a previously persisted Conversation file
  When I load the Conversation from storage
  Then the loaded Conversation contains the same Chats and Messages as the original
  and the order of Chats and Messages is preserved

Scenario: Load fails for corrupt or missing data
  Given a missing or corrupt persistence file
  When I attempt to load a Conversation from storage
  Then a clear error is raised
  and no partial Conversation is returned

Scenario: Overwrite an existing persisted Conversation
  Given an existing persisted Conversation file
  When I persist a new Conversation to the same storage location
  Then the old Conversation is replaced by the new one
  and loading from that location returns the new Conversation
```
