## US-000035 — GUI Integration: ScopeAgent Option

### User Story

```
AS A Product Owner
I WANT to switch to/start a new scoping session from the the GUI
SO THAT I can start a scoping session with the LLM
```

### Acceptance Criteria

```gherkin
Scenario: User initiates scoping phase via GUI menu
  Given ViberFX standalone application is running
  When the user selects the "Start Scoping Phase" menu item
  Then the system loads the ScopeAgent
  And the UI indicates scoping phase mode
  And the conversation is ready for scoping interaction

Scenario: User switches actor to ScopeAgent via actor selector
  Given a chat session is active in the GUI
  When the user selects "ScopeAgent" from the actor selector
  And confirms the selection
  Then the system switches to the ScopeAgent for subsequent interactions
  And the UI indicates scoping phase mode
  And the existing conversation history remains accessible

Scenario: Visual indication distinguishes scoping phase from general chat
  Given a scoping session is active in the GUI
  When I observe the UI
  Then there is a clear visual indicator (e.g., badge, color, label) showing "Scoping Phase"
  And the indicator is distinct from regular chat mode

Scenario: GUI AskTools integration works with ScopeAgent
  Given a scoping session is running in GUI mode
  When ScopeAgent invokes an AskTools method
  Then ViberGUIAskTools displays a modal dialog
  And the user response is returned to the agent
```
