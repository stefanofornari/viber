## US-000037 — CLI Scoping Phase Indication

### User Story

```
AS A Product Owner
I WANT to receive a clear textual indication when I am in the scoping phase (in CLI mode)
SO THAT I am aware of the current phase and can adjust my expectations accordingly
```

### Acceptance Criteria

```gherkin
Scenario: CLI indicates scoping phase activation
  Given I have activated the scoping phase via the GUI menu
  When I view the CLI output
  Then I see a clear textual indicator showing "Scoping Phase Active"
  And the indicator is distinct from regular chat mode indicators

Scenario: CLI indication persists throughout session
  Given I am in a scoping phase session in CLI mode
  When I exchange multiple messages with ScopeAgent
  Then the scoping phase indication remains visible
  And does not interfere with message display

Scenario: CLI indication clears on phase exit
  Given I am in a scoping phase session
  When the scoping phase completes and returns to normal operation
  Then the scoping phase indication is no longer visible
  And regular chat indicators resume
```
