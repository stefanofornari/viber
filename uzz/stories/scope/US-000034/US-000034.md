## US-000034 — CLI Integration: ScopeActor Selection

### User Story

```
AS A Product Owner
I WANT to start a scoping session directly from the terminal with a single flag
SO THAT I can begin defining my product scope without navigating menus
```

### Acceptance Criteria

```gherkin
Scenario: Start scoping session with --scope flag
  Given I run `viber --scope` in my terminal
  When Viber starts
  Then I am immediately in a scoping session
  And I can start describing my product idea

Scenario: Start scoping session with --agent=scope flag
  Given I run `viber --agent=scope` in my terminal
  When Viber starts
  Then I am immediately in a scoping session

Scenario: Scoping session uses the correct prompt
  Given I start a CLI scoping session
  When the session initializes
  Then the AI introduces itself as a scoping assistant
  And guides me through the scoping process

Scenario: Conversation history is preserved during the session
  Given I am in a CLI scoping session
  When I exchange multiple messages with ScopeAgent
  Then the full conversation history is maintained
  And I can refer back to earlier parts of our discussion
```
