## US-000038 — Next Steps Suggestion After Scoping Phase

### User Story

```
AS A Product Owner
I WANT the system to suggest next steps after the scoping phase completes
SO THAT I know what to do with the generated scope document
```

#### Status
BLOCKED
The agent must provide a way to detect when it things it has done.


#### Dependencies
- US-000031
- US-000036

#### Technical Context & Constraints
* **Target System**: Java application (both GUI and CLI modes)
* **Toolchain / Rules**: Java, Maven per `uzz/project/development-framework.md`; TDD workflow per `uzz/project/development-framework.md`
* **Dependency**: Requires successful generation of scope document
* **Phase**: MVP

#### Notes
See `notes.md`

### Acceptance Criteria

```gherkin
Scenario: System suggests next steps upon completion
  Given I have completed a scoping phase session
  When the scoping phase ends
  Then the system displays suggestions for next steps
  And the suggestions include options to proceed to story generation or code implementation

Scenario: Next steps are context-appropriate
  Given I have completed a scoping phase for a feature
  When the system suggests next steps
  Then the suggestions are relevant to the scoping output
  And suggest logical progression in the Scope → Story → Code workflow

Scenario: Next steps work in both GUI and CLI
  Given I have completed a scoping phase session
  When the scoping phase ends in either GUI or CLI mode
  Then appropriate next steps are suggested in the respective interface
  And the suggestions are actionable within each interface
```
