## US-000033 — GUI AskTools Implementation

### User Story

```
AS A Product Owner
I WANT to answer clarifying questions through a GUI dialog during scoping
SO THAT the ScopeAgent can gather the details needed to generate my product scope
```

### Acceptance Criteria

```gherkin
Scenario: Answer clarifying questions in GUI mode
  Given I am in a GUI scoping session
  When ScopeAgent asks a clarifying question
  Then a modal dialog appears with the question
  And I can type my answer in the dialog
  And my answer is sent back to ScopeAgent when I confirm

Scenario: Multiple questions are handled sequentially in GUI
  Given I am in a GUI scoping session
  When ScopeAgent has multiple clarifying questions
  Then each question appears in its own dialog
  And I answer each before the next appears

Scenario: My answers are incorporated into the scope
  Given I have answered clarifying questions in the GUI
  When the scope document is generated
  Then my answers are reflected in the relevant sections
```
