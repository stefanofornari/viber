## US-000032 — CLI AskTools Implementation

### User Story

```
AS A Product Owner
I WANT to answer clarifying questions in the terminal during scoping
SO THAT the ScopeAgent can gather the details needed to generate my product scope
```

### Acceptance Criteria

```gherkin
Scenario: Answer clarifying questions in CLI mode
  Given I am in a CLI scoping session
  When ScopeAgent asks a clarifying question
  Then the question appears in my terminal
  And I can type my answer
  And my answer is sent back to ScopeAgent

Scenario: Multiple questions are handled sequentially
  Given I am in a CLI scoping session
  When ScopeAgent has multiple clarifying questions
  Then each question is presented one at a time
  And I answer each before the next appears

Scenario: My answers are incorporated into the scope
  Given I have answered clarifying questions in CLI
  When the scope document is generated
  Then my answers are reflected in the relevant sections
```
