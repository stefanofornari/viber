## US-000066 — Edit Story Dependencies

### User Story

```
AS A User
I WANT to edit the dependencies of a story as a comma-separated list of IDs in the editor
SO THAT I can keep the story's ordering constraints accurate
```

#### Status
DONE

#### Dependencies
- US-000065

#### Technical Context & Constraints
* **Target System**: UserStoryEditor FXML view
* **Toolchain / Rules**: JavaFX FXML, AtlantaFX, TestFX headless, AssertJ BDD

#### Notes
1. Dependencies are edited in a single text field, e.g. `US-000001, US-000002`, kept in sync with the model's dependency list.
2. Entries are trimmed; blank entries and duplicates are ignored.
3. No check that the referenced story exists; constraining input to existing stories is deferred to US-000076.

### Acceptance Criteria

```gherkin
Scenario: Add a dependency
  Given the editor shows a story with no dependencies
  When the user types "US-000010" in the dependencies field
  Then the model contains "US-000010"

Scenario: Several dependencies
  Given the editor shows a story with no dependencies
  When the user types " US-000001 ,US-000002 "
  Then the model contains "US-000001" and "US-000002" in that order

Scenario: Remove all dependencies
  Given the editor shows a story depending on "US-000010"
  When the user clears the dependencies field
  Then the model has no dependencies

Scenario: Blank or duplicate entry
  When the user types "US-000010, , US-000010"
  Then the model contains "US-000010" only once
```
