## US-000070 — Raw Markdown Tab Synchronized with Structured View

### User Story

```
AS A User
I WANT a raw-markdown tab that shows and edits the story as plain text, in sync with the structured fields
SO THAT I can make edits that the structured view does not cover, or paste a whole story
```

#### Technical Context & Constraints
* **Target System**: UserStoryEditor FXML view
* **Toolchain / Rules**: JavaFX FXML (`TabPane`, `TextArea`), AtlantaFX, TestFX headless, AssertJ BDD

#### Notes
1. Plain `TextArea`; no rich-text or syntax highlighting (a WYSIWYG editor such as Milkdown may be considered later).
2. Structured to raw: refreshed whenever the model changes.
3. Raw to structured: applied when the user leaves the raw tab; invalid markdown is reported and does not replace the model.

### Acceptance Criteria

```gherkin
Scenario: Raw tab reflects structured edits
  Given the editor shows a story
  When the user changes the title in the structured view and opens the raw tab
  Then the raw text contains the new title

Scenario: Structured view reflects raw edits
  Given the raw tab is open
  When the user edits the status line and returns to the structured tab
  Then the status dropdown shows the new status

Scenario: Invalid raw text
  Given the raw tab is open
  When the user removes the "AS A / I WANT / SO THAT" block and returns to the structured tab
  Then an error is reported to the user
  And the model keeps its previous values
```
