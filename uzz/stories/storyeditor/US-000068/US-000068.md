## US-000068 — Edit Technical Context and Notes

### User Story

```
AS A User
I WANT to edit a story's technical context and notes in the editor
SO THAT I can complete the story's non-functional details alongside its acceptance criteria
```

#### Status
DONE

#### Dependencies
- US-000065

#### Technical Context & Constraints
* **Target System**: UserStoryEditor FXML view
* **Toolchain / Rules**: JavaFX FXML, AtlantaFX, TestFX headless, AssertJ BDD

#### Notes
1. Both are multi-line plain-text areas bound to the model.
2. Multi-line content, including blank lines, is preserved on render.
3. The editor is split into three tabs: Main (header fields), Acceptance criteria and Notes (technical context and notes).

### Acceptance Criteria

```gherkin
Scenario: Show technical context and notes
  Given a story with technical context and notes
  When it is set on the editor
  Then both text areas show the content

Scenario: Edit notes
  Given the editor shows a story
  When the user types multi-line text in the notes area
  Then the model's notes hold the same multi-line text

Scenario: Empty sections
  Given a story with no notes
  When it is set on the editor
  Then the notes area is empty and editable
```
