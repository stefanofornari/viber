## US-000075 — UserStoryEditor in the Manual Actor Dev Mode Window

### User Story

```
AS A Developer
I WANT the UserStoryEditor available in the Manual Actor's dev mode window
SO THAT I can open, edit and save a story file and try an LLM-proposed story without a separate demo application
```

#### Status
DONE

#### Dependencies
- US-000069
- US-000016

#### Technical Context & Constraints
* **Target System**: `DevModeWindow` / `DevModeController` used with `FXActor`
* **Toolchain / Rules**: JavaFX FXML, AtlantaFX, TestFX headless, AssertJ BDD
* **Phase**: Hosting only; no wiring into the chat flow or other actors

#### Notes
1. Added as an additional view in the existing dev mode window, alongside the conversation editor (US-000016).
2. Actions: open story file, save, and load a built-in sample "LLM-proposed" story (via `load(String)`, US-000069).
3. Editor errors are shown to the user in the window.

### Acceptance Criteria

```gherkin
Scenario: Open and edit a story file
  Given the dev mode window is open
  When the Developer opens a story markdown file in the story editor view
  Then the editor shows the story and allows edits

Scenario: Save the edited story
  Given an edited story in the dev mode story editor view
  When the Developer saves it
  Then the file contains the edits

Scenario: Load the sample LLM proposal
  Given the dev mode window is open
  When the Developer chooses the sample LLM-proposed story
  Then the editor shows it as the current story

Scenario: Invalid file
  Given the dev mode window is open
  When the Developer opens a file that is not a story
  Then an error is shown and the editor keeps its current content
```
