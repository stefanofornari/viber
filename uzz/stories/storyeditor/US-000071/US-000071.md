## US-000071 — Markdown Preview Button

### User Story

```
AS A User
I WANT a Preview button on the raw-markdown tab that renders the story's markdown
SO THAT I can see how the story reads before saving it
```

#### Status
TODO

#### Dependencies
- US-000070

#### Technical Context & Constraints
* **Target System**: UserStoryEditor raw-markdown tab
* **Toolchain / Rules**: JavaFX FXML, existing `javafx-markdown-preview` dependency, AtlantaFX, TestFX headless, AssertJ BDD

#### Notes
1. Preview is read-only and renders the current raw text, including unsaved edits.
2. Toggling the button again returns to the plain-text editor.

### Acceptance Criteria

```gherkin
Scenario: Show the preview
  Given the raw tab shows the story markdown
  When the user presses Preview
  Then the rendered markdown is displayed in place of the text area

Scenario: Preview includes unsaved edits
  Given the user has edited the raw text without saving
  When the user presses Preview
  Then the rendered output reflects the edited text

Scenario: Return to editing
  Given the preview is displayed
  When the user presses the button again
  Then the plain-text editor is shown with the raw text unchanged
```
