## US-000073 — Read-Only Mode

### User Story

```
AS A Developer
I WANT to switch the editor into read-only mode
SO THAT a story can be shown for review without being modified
```

#### Technical Context & Constraints
* **Target System**: UserStoryEditor public API
* **Toolchain / Rules**: JavaFX properties, TestFX headless, AssertJ BDD

#### Notes
1. A boolean `readOnly` property; when true all inputs and list actions are disabled, text remains selectable and the preview still works.

### Acceptance Criteria

```gherkin
Scenario: Enable read-only mode
  Given an editor showing a story
  When the Developer sets readOnly to true
  Then no field, list action or raw text can be edited
  And the content remains visible and selectable

Scenario: Disable read-only mode
  Given a read-only editor
  When the Developer sets readOnly to false
  Then all fields are editable again

Scenario: Programmatic changes still shown
  Given a read-only editor
  When the Developer changes the story model
  Then the UI shows the new values
```
