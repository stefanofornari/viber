## US-000065 — UserStoryEditor Control with Header Fields

### User Story

```
AS A Developer
I WANT an FXML-based UserStoryEditor control, styled with AtlantaFX, that shows and edits a story's ID, title, role, want, so-that and status
SO THAT I can embed a visual story editor in any JavaFX scene and bind it to a UserStory
```

#### Status
DONE

#### Dependencies
- US-000064

#### Technical Context & Constraints
* **Target System**: JavaFX control with FXML layout and controller, own package
* **Toolchain / Rules**: Java, JavaFX FXML, AtlantaFX (existing dependency), TestFX headless, AssertJ BDD; `uzz/project/coding_standard.md`

#### Notes
1. The control exposes a `story` property (`ObjectProperty<UserStory>`); setting it refreshes the UI, editing the UI updates the model.
2. Status is chosen from a dropdown (`TODO`, `WIP`, `DONE`, `BLOCKED`).
3. The UI is defined in FXML; no layout is built in code.
4. With no story set, the fields are empty and disabled.

### Acceptance Criteria

```gherkin
Scenario: Show a story's header fields
  Given a UserStoryEditor in a scene
  When the Developer sets a story on the story property
  Then the ID, title, role, want, so-that and status controls show the story's values

Scenario: Editing the UI updates the model
  Given a UserStoryEditor showing a story
  When the user types a new title
  Then the story's title property holds the new title

Scenario: Model changes update the UI
  Given a UserStoryEditor showing a story
  When the Developer changes the story's want programmatically
  Then the want field shows the new value

Scenario: No story loaded
  Given a UserStoryEditor with no story
  Then all fields are empty and disabled
```
