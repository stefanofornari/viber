## US-000067 — Edit Gherkin Acceptance Scenarios

### User Story

```
AS A User
I WANT to add, edit, remove and reorder the Gherkin scenarios of a story in the editor
SO THAT I can refine a story's acceptance criteria visually
```

#### Status
DONE

#### Dependencies
- US-000065

#### Technical Context & Constraints
* **Target System**: UserStoryEditor FXML view
* **Toolchain / Rules**: JavaFX FXML, AtlantaFX, TestFX headless, AssertJ BDD

#### Notes
1. Each scenario is edited as text (title plus Given/When/Then lines); no Gherkin semantic validation.
2. Each scenario has an icon "up" button (the first wraps to the last) and a delete icon button that turns into undo; add is a + icon button above the list. Icons are Feather, as elsewhere in viber.
3. A new scenario starts with a template skeleton.
4. Scenarios are listed in a scrollable pane as collapsible panes, collapsed by default and showing only the title (first line).

### Acceptance Criteria

```gherkin
Scenario: Add a scenario
  Given the editor shows a story with two scenarios
  When the user adds a scenario
  Then the model has three scenarios and the new one is shown expanded for editing

Scenario: Edit a scenario
  Given the editor shows a story
  When the user changes the text of the first scenario
  Then the model's first scenario holds the new text

Scenario: Remove a scenario
  Given the editor shows a story with two scenarios
  When the user deletes the first one
  Then the model has one scenario, the former second, and the deleted one stays listed collapsed with an undo button

Scenario: Undo a deletion
  Given the user has deleted the second of three scenarios
  When the user presses undo
  Then the model has three scenarios again, in the original order

Scenario: Reorder scenarios
  Given the editor shows a story with two scenarios
  When the user presses up on the second scenario
  Then the model lists the former second scenario first

Scenario: Up on the first scenario wraps around
  Given the editor shows a story with three scenarios
  When the user presses up on the first scenario
  Then the model lists it last
```
