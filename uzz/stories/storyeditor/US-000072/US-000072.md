## US-000072 — Unsaved-Changes Indication

### User Story

```
AS A User
I WANT the editor to show visibly whether the story has unsaved changes
SO THAT I do not lose edits by accident
```

#### Technical Context & Constraints
* **Target System**: UserStoryEditor control and FXML view
* **Toolchain / Rules**: JavaFX properties, AtlantaFX, TestFX headless, AssertJ BDD

#### Notes
1. The control exposes a read-only `dirty` property hosts can observe.
2. Reverting a field to its original value does not need to clear the flag.

### Acceptance Criteria

```gherkin
Scenario: Clean after load
  Given a story has just been loaded
  Then the dirty property is false and no indicator is shown

Scenario: Dirty after edit
  Given a loaded story
  When the user edits any field
  Then the dirty property is true and the indicator is shown

Scenario: Clean after save
  Given a dirty story
  When it is saved successfully
  Then the dirty property is false and the indicator is hidden

Scenario: Failed save keeps dirty
  Given a dirty story
  When saving fails
  Then the dirty property stays true
```
