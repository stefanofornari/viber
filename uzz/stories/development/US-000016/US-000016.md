## US-000016 — Dev Mode Conversation Editor

### User Story

```
AS A User
I WANT a dev mode window with a text area and button bar to manually add chats and messages to a conversation
SO THAT I can test the JavaFX conversation rendering and model behavior interactively
```

#### Status
DONE

#### Dependencies
- US-000017
- US-000018

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: JavaFX, FXML descriptors whenever possible per `project/development-framework.md`; UI construction separate from business logic per `project/coding-standard.md`; host application controls the window per `project/coding-standard.md`
* **Renderer contract**: The dev window reuses the existing `GUIRenderer` and must not create additional `Stage` instances; the window embeds the renderer's root node
* **Positioning**: The dev window must appear adjacent to the main application window, with both windows centered on screen; it must open only after the main window is showing
* **Phase**: MVP

#### Notes
See `notes.md`

### Acceptance Criteria

```gherkin
Scenario: Dev window opens with --gui flag
  Given ViberCLI is started with the --gui flag
  When the application initializes
  Then a JavaFX window opens containing a multi-line text component on top
  And a button bar below the text component

Scenario: Button bar contains all message action buttons
  Given the dev window is open
  When I inspect the button bar
  Then the button bar contains buttons labeled: Add Chat, Add Reply, Add Thought, Add Tool Execution, Add Tool Reply, Add Error

Scenario: Buttons are disabled when text is blank
  Given the dev window is open
  And the text component is empty
  When I inspect the button states
  Then all message action buttons are disabled

Scenario: Buttons are enabled when text is present
  Given the dev window is open
  And the text component contains non-blank text
  When I inspect the button states
  Then all message action buttons are enabled

Scenario: Add Chat creates a new chat tab
  Given the dev window is open
  And the text component contains "some prompt"
  When I press the Add Chat button
  Then a new Chat tab is added to the discussion window
  And the chat contains a PromptMessage with the provided text

Scenario: Add Reply appends a reply message to the current chat
  Given the dev window is open
  And a chat is selected
  And the text component contains "some reply"
  When I press the Add Reply button
  Then a ReplyMessage with the provided text is appended to the current chat

Scenario: Add Thought appends a thought message to the current chat
  Given the dev window is open
  And a chat is selected
  And the text component contains "some thought"
  When I press the Add Thought button
  Then a ThoughtMessage with the provided text is appended to the current chat

Scenario: Add Tool Execution appends a tool request message to the current chat
  Given the dev window is open
  And a chat is selected
  And the text component contains "tool(args)"
  When I press the Add Tool Execution button
  Then a ToolInvocationMessage with the provided text is appended to the current chat

Scenario: Add Tool Reply appends a tool response message to the current chat
  Given the dev window is open
  And a chat is selected
  And the text component contains "tool result"
  When I press the Add Tool Reply button
  Then a ToolExecutionMessage with the provided text is appended to the current chat

Scenario: Add Error appends an error message to the current chat
  Given the dev window is open
  And a chat is selected
  And the text component contains "something went wrong"
  When I press the Add Error button
  Then an ErrorMessage with the provided text is appended to the current chat

Scenario: Message is created with text from the text component
  Given the dev window is open
  And the text component contains "hello world"
  When I press any message action button
  Then the created message contains exactly the text "hello world"

Scenario: Empty text prevents message creation
  Given the dev window is open
  And the text component is empty
  When I press any message action button
  Then no message is created
  And the conversation remains unchanged
```
