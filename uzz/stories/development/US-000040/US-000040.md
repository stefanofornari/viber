## US-000040 — Dev Mode AskTools Menu Button

### User Story

```
AS A Developer
I WANT a menu button in the dev mode window to add AskTools invocations (AskQuestion, AskSingleChoice, AskMultipleChoice, AskConfirmation)
SO THAT I can test how AskTools render in the chat window
```

#### Status
DONE

#### Dependencies
- US-000016

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application (Dev Mode Window)
* **Toolchain / Rules**: JavaFX, FXML descriptors whenever possible per `project/development-framework.md`; UI construction separate from business logic per `project/coding-standard.md`
* **Renderer contract**: The dev window reuses the existing `GUIRenderer` and must not create additional `Stage` instances
* **Phase**: MVP

#### Notes
1. The menu button should be added to the existing button bar in `DevModeWindow.fxml`
2. The menu button should provide four menu items: AskQuestion, AskSingleChoice, AskMultipleChoice, AskConfirmation
3. When a menu item is selected, the corresponding JSON tool invocation template should be inserted into the text area
4. The JSON format follows the `QuestionJSONObject` structure:
   - AskQuestion: `{"tool":"AskQuestion","arguments":{"question":""}}`
   - AskSingleChoice: `{"tool":"AskSingleChoice","arguments":{"question":"","options":[]}}`
   - AskMultipleChoice: `{"tool":"AskMultipleChoice","arguments":{"question":"","options":[]}}`
   - AskConfirmation: `{"tool":"AskConfirmation","arguments":{"question":""}}`
5. Keep the AskTools menu enabled so a tool type can be selected regardless of text area content

### Acceptance Criteria

```gherkin
Scenario: Menu button appears in dev window button bar
  Given the dev window is open
  When I inspect the button bar
  Then a menu button labeled "Add AskTool" is present
  And the menu button contains four items: "AskQuestion", "AskSingleChoice", "AskMultipleChoice", "AskConfirmation"

Scenario: Selecting AskQuestion inserts JSON template
  Given the dev window is open
  When I click the "Add AskTool" menu button
  And I select "AskQuestion"
  Then the text area contains: {"tool":"AskQuestion","arguments":{"question":"Enter your question here"}}

Scenario: Selecting AskSingleChoice inserts JSON template
  Given the dev window is open
  When I click the "Add AskTool" menu button
  And I select "AskSingleChoice"
  Then the text area contains: {"tool":"AskSingleChoice","arguments":{"question":"Enter your question here","options":["Option 1","Option 2"]}}

Scenario: Selecting AskMultipleChoice inserts JSON template
  Given the dev window is open
  When I click the "Add AskTool" menu button
  And I select "AskMultipleChoice"
  Then the text area contains: {"tool":"AskMultipleChoice","arguments":{"question":"Enter your question here","options":["Option 1","Option 2"]}}

Scenario: Selecting AskConfirmation inserts JSON template
  Given the dev window is open
  When I click the "Add AskTool" menu button
  And I select "AskConfirmation"
  Then the text area contains: {"tool":"AskConfirmation","arguments":{"question":"Enter your question here"}}

Scenario: Menu button remains enabled when text area is not empty
  Given the dev window is open
  And the text area contains non-blank text
  When I inspect the "Add AskTool" menu button state
  Then the menu button is enabled

Scenario: Menu button is enabled when text area is empty
  Given the dev window is open
  And the text area is empty
  When I inspect the "Add AskTool" menu button state
  Then the menu button is enabled

Scenario Outline: Answering an AskTool appends the result to the chat
  Given a chat is active in the dev window
  And a valid "<tool>" invocation is submitted with "Add Tool Execution"
  And an "<tool>" question is displayed
  When I provide "<answer>" and click "Answer"
  Then the question panel disappears
  And the chat shows a "VIBER / TOOL_EXECUTION_RESPONSE" pane
  And the question appears in italics as a quote starting with ">"
  And the response appears indented directly below the question
  And no AskTools invocation pane is shown in the chat

  Examples:
    | tool              | answer    | result    |
    | AskQuestion       | My name   | My name   |
    | AskSingleChoice   | Beta      | Beta      |
    | AskMultipleChoice | Alpha     | [Alpha]   |
    | AskConfirmation   | No        | false     |

Scenario: Consecutive AskTool answers are grouped as tool responses
  Given a chat with two answered AskTool invocations
  When I inspect the chat pane
  Then the consecutive tool response contents are appended to one "VIBER / TOOL_EXECUTION_RESPONSE" pane
```
