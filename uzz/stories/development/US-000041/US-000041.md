## US-000041 — Dev Mode AskTools JSON Validation and Error Handling

### User Story

```
AS A Developer
I WANT JSON validation with error reporting when using AskTools menu items in dev mode
SO THAT I can detect and fix malformed tool invocation JSON before sending it
```

#### Status
TODO

#### Dependencies
- US-000040

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application (Dev Mode Window)
* **Toolchain / Rules**: JavaFX, FXML descriptors whenever possible per `project/development-framework.md`; UI construction separate from business logic per `project/coding-standard.md`
* **Error handling pattern**: Follow the existing pattern in `DevModeController.handleAddToolInvocation()` which catches JSON parsing exceptions and reports errors via `fxActor.addError()`
* **Phase**: MVP

#### Notes
1. When the user presses one of the existing message action buttons (Add Chat, Add Reply, Add Thought, Add Tool Execution, Add Tool Reply, Add Error) with AskTools JSON in the text area, the JSON should be validated
2. If JSON is invalid (malformed, missing required fields, wrong structure), an error should be reported using the existing error reporting mechanism
3. The validation should check:
   - Valid JSON syntax
   - Presence of "tool" field with valid AskTools name (AskQuestion, AskSingleChoice, AskMultipleChoice, AskConfirmation)
   - Presence of "arguments" object
   - For AskQuestion/AskConfirmation: "question" field in arguments
   - For AskSingleChoice/AskMultipleChoice: "question" field and "options" array in arguments
4. Error reporting should follow the same pattern as `handleAddToolInvocation()` - use `fxActor.addError()` with descriptive message
