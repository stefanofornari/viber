## US-000059 — Conversation History Maintenance in Coding Phase

### User Story

```
AS A Developer
I WANT the conversation history to be maintained within the coding phase chat
SO THAT I can refer back to earlier parts of the coding discussion
```

#### Technical Context & Constraints

#### Notes
1. Mirror conversation-history behavior for the existing scoping and story-generation phases.
2. Keep coding-phase messages accessible after the user explicitly returns to LangChain4jActor.

### Acceptance Criteria

```gherkin
Scenario Outline: Coding conversation history is preserved
  Given a coding phase session is active in "<interface>"
  When I exchange multiple messages with CodingActor
  Then the full conversation history is maintained in the correct order
  And I can refer back to earlier parts of the coding discussion

  Examples:
    | interface |
    | ViberFX   |
    | ViberCLI  |

Scenario: Message ordering is maintained
  Given a coding phase session is active
  When I send a prompt and receive an agent response
  Then the prompt appears before its response in the conversation history
  And each message is associated with the coding phase chat

Scenario: Coding history remains accessible after returning to normal operation
  Given I have explicitly returned to LangChain4jActor after a coding phase
  When I revisit the coding phase chat
  Then the coding phase messages remain available in their original order
  And subsequent normal-operation messages do not replace or mix with that history
```
