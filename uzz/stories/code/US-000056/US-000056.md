## US-000056 — GUI Integration: Return to Normal Operation After Coding Phase

### User Story

```
AS A Developer
I WANT to explicitly leave CodingActor in the GUI
SO THAT I can resume regular interactions
```

#### Technical Context & Constraints
* **Target System**: ViberFX standalone JavaFX application
* **Toolchain / Rules**: Java 21, JavaFX, Maven; follow `uzz/project/development-framework.md` and `uzz/project/coding-standard.md`

#### Notes
1. Exiting the coding phase is an explicit user action; do not infer completion from agent response text.

### Acceptance Criteria

```gherkin
Scenario: User returns to the normal actor
  Given CodingActor is active in ViberFX
  When the user explicitly selects LangChain4jActor
  Then subsequent prompts are handled by LangChain4jActor
  And the Coding Phase indication is removed

Scenario: CodingActor completion text does not switch actors
  Given CodingActor is active in ViberFX
  When its response indicates that the coding work is complete
  Then CodingActor remains active until the user explicitly switches actors
```
