## US-000058 — CLI Coding Phase Indication

### User Story

```
AS A Developer
I WANT a clear textual indication when CodingActor is active in ViberCLI
SO THAT I know which phase is handling my coding requests
```

#### Status
TODO

#### Dependencies
- US-000055
- US-000057

#### Technical Context & Constraints
* **Target System**: ViberCLI terminal application
* **Toolchain / Rules**: Java 21, Maven; follow `uzz/project/development-framework.md` and `uzz/project/coding-standard.md`

#### Notes
1. Follow the existing CLI phase-indication patterns for scoping and story generation.
2. The indication must remain distinct from normal chat and the other phases, and must not interfere with message output.

### Acceptance Criteria

```gherkin
Scenario: CLI indicates CodingActor activation
  Given ViberCLI is running
  When the user activates CodingActor
  Then the CLI displays "Coding Phase Active"
  And the indication is distinct from normal chat, scoping, and story-generation indications

Scenario: CLI indication persists throughout the coding session
  Given CodingActor is active in ViberCLI
  When the user exchanges multiple messages with CodingActor
  Then the Coding Phase indication remains visible
  And it does not interfere with message display

Scenario: CLI indication clears when the user exits the coding phase
  Given CodingActor is active in ViberCLI
  When the user explicitly switches to LangChain4jActor
  Then the Coding Phase indication is no longer displayed
  And normal actor indication resumes
```
