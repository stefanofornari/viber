## US-000047 — CLI Integration: StoryActor Selection

### User Story

```
AS A Product Owner
I WANT to start a story generation session directly from the terminal with a single flag
SO THAT I can begin generating user stories from my scope document without navigating menus
```

### Acceptance Criteria

```gherkin
Scenario: Start story generation session with --story flag
  Given I run `viber --story` in my terminal
  When Viber starts
  Then I am immediately in a story generation session
  And I can start describing my scope or providing a scope file path

Scenario: Start story generation session with --agent=story flag
  Given I run `viber --agent=story` in my terminal
  When Viber starts
  Then I am immediately in a story generation session

Scenario: Story generation session uses the correct prompt
  Given I start a CLI story generation session
  When the session initializes
  Then the AI introduces itself as a story generation assistant
  And guides me through the story generation process

Scenario: Conversation history is preserved during the session
  Given I am in a CLI story generation session
  When I exchange multiple messages with StoryActor
  Then the full conversation history is maintained
  And I can refer back to earlier parts of our discussion
```
