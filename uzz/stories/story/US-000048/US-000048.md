## US-000048 — GUI Integration: StoryActor Option

### User Story

```
AS A Product Owner
I WANT to switch to/start a new story generation session from the GUI
SO THAT I can start a story generation session with the LLM
```

#### Status
DONE

#### Dependencies
- US-000044
- US-000035

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: Java, JavaFX, Maven per `uzz/project/development-framework.md`; TDD workflow per `uzz/project/development-framework.md`
* **Dependency**: Visual indication of story generation phase distinct from general chat
* **Phase**: MVP

#### Notes
Mirrors the GUI Integration for ScopeAgent (US-000035) but for story generation phase.

### Acceptance Criteria

```gherkin
Scenario: User initiates story generation phase via GUI menu
  Given ViberFX standalone application is running
  When the user selects the "Start Story Generation Phase" menu item
  Then the system loads the StoryActor
  And the UI indicates story generation phase mode
  And the conversation is ready for story generation interaction

Scenario: User switches actor to StoryActor via actor selector
  Given a chat session is active in the GUI
  When the user selects "StoryActor" from the actor selector
  And confirms the selection
  Then the system switches to the StoryActor for subsequent interactions
  And the UI indicates story generation phase mode
  And the existing conversation history remains accessible

Scenario: Visual indication distinguishes story generation phase from general chat
  Given a story generation session is active in the GUI
  When I observe the UI
  Then there is a clear visual indicator (e.g., badge, color, label) showing "Story Generation Phase"
  And the indicator is distinct from regular chat mode and scoping phase

Scenario: GUI AskTools integration works with StoryActor
  Given a story generation session is running in GUI mode
  When StoryActor invokes an AskTools method
  Then ViberGUIAskTools displays a modal dialog
  And the user response is returned to the agent
```
