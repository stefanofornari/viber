## US-000050 — CLI Story Generation Phase Indication

### User Story

```
AS A Product Owner
I WANT to receive a clear textual indication when I am in the story generation phase (in CLI mode)
SO THAT I am aware of the current phase and can adjust my expectations accordingly
```

#### Notes
Mirrors the CLI scoping phase indication (US-000037) but for story generation phase.

### Acceptance Criteria

```gherkin
Scenario: CLI indicates story generation phase activation
  Given I have activated the story generation phase via the GUI menu
  When I view the CLI output
  Then I see a clear textual indicator showing "Story Generation Phase Active"
  And the indicator is distinct from regular chat mode indicators and scoping phase indicators

Scenario: CLI indication persists throughout session
  Given I am in a story generation phase session in CLI mode
  When I exchange multiple messages with StoryActor
  Then the story generation phase indication remains visible
  And does not interfere with message display

Scenario: CLI indication clears on phase exit
  Given I am in a story generation phase session
  When the story generation phase completes and returns to normal operation
  Then the story generation phase indication is no longer visible
  And regular chat indicators resume
```
