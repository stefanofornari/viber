## US-000030 — Tool Invocation and Execution Result Rendering

### User Story

```
AS A user
I WANT to see tool invocation arguments and execution results rendered together in the conversation view
SO THAT I can understand what tools were called and what they returned without leaving the conversation
```

#### Status
DONE

#### Dependencies
- US-000014

#### Technical Context & Constraints
* **Target System**: Standalone JavaFX desktop application / embeddable JavaFX component
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `project/development-framework.md`; FXML descriptors whenever possible; UI construction separate from business logic per `project/coding-standard.md`
* **Styling**: Colors via CSS custom properties in `viber.css`; no hardcoded colors or fonts in Java code
* **Phase**: MVP

#### Notes
See `notes.md`

### Acceptance Criteria

```gherkin
Scenario: Tool invocation message appears in conversation
  Given a Conversation contains a ToolInvocationMessage
  When the conversation is rendered in the JavaFX view
  Then the message pane shows the tool name and each argument as a labeled chip
  And the pane is styled distinctly from prompts, replies, and thoughts

Scenario: Tool execution result appears below invocation
  Given a ToolInvocationMessage is displayed in the conversation
  And a ToolExecutionMessage follows it in the same Chat
  When the execution message is rendered
  Then the result text appears below the argument chips in the same pane
  And the result supports markdown rendering

Scenario: Consecutive tool invocations create separate panes
  Given two ToolInvocationMessages appear consecutively in a Chat
  When the conversation is rendered
  Then each invocation gets its own pane
  And the panes are visually separated

Scenario: Execution without prior invocation renders gracefully
  Given a ToolExecutionMessage appears without a preceding ToolInvocationMessage in the Chat
  When the conversation is rendered
  Then a tool pane is created showing only the execution result
  And no arguments panel is shown
```
