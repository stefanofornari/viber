## US-000022 — Actor Settings Configuration

### User Story

```
AS A user
I WANT to configure the LangChain4jActor settings (API key, model, endpoint) from the GUI
SO THAT I can use the LangChain4jActor without having to restart the application or use command-line flags
```

### Acceptance Criteria

```gherkin
Scenario: Actor Settings menu item is visible
  Given the ViberFX standalone application is running
  When I inspect the Actor menu
  Then a "Settings..." option is visible at the bottom of the Actor menu

Scenario: Actor Settings dialog opens with current values
  Given the ViberFX standalone application is running
  When I select "Settings..." from the Actor menu
  Then a dialog opens with fields for API Key, Endpoint, Model, and System Prompt
  And the fields are pre-filled with the current values or defaults

Scenario: Saving settings creates LangChain4jActor with provided values
  Given the Actor Settings dialog is open
  And I enter a valid API key, endpoint, model, and system prompt
  When I click Save
  Then the settings are saved
  And a LangChain4jActor is created with the provided configuration
  And the active actor switches to LangChain4jActor

Scenario: Canceling settings dialog does not change actor
  Given the Actor Settings dialog is open
  When I click Cancel
  Then the dialog closes
  And the active actor remains unchanged

Scenario: Invalid endpoint shows error
  Given the Actor Settings dialog is open
  And I enter an invalid endpoint URL
  When I click Save
  Then an error message is shown
  And the dialog remains open

Scenario: Settings persist for the session
  Given I have configured LangChain4jActor settings
  When I switch to FXActor and back to LangChain4jActor
  Then the previously entered settings are used
```
