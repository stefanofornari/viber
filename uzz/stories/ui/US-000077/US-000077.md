## US-000077 — Chat Activity Indicator in the Chat Tab

### User Story

```
AS A User
I WANT to see which chats have a communication in progress
SO THAT I know a chat is still working, even when it is not the selected tab
```

#### Status
DONE

#### Dependencies
- None

#### Technical Context & Constraints
* **Target System**: Standalone ViberFX desktop application
* **Toolchain / Rules**: Java 21, JavaFX 23.0.2, CommonsFX, AtlantaFX, and Maven; follow `uzz/project/coding_standard.md` and `uzz/project/development_framework.md`

#### Notes
1. The indicator sits to the left of the chat label in the tab title (e.g. `<indicator> <label> <archive> <delete>` when those buttons are present).
2. Use AtlantaFX `RingProgressIndicator` in indeterminate mode, e.g.:
   ```java
   RingProgressIndicator ringProgress = new RingProgressIndicator(0, false);
   ringProgress.setMinSize(32, 32);
   ringProgress.setProgress(ProgressIndicator.INDETERMINATE_PROGRESS);
   ```
3. When the chat is idle no icon is displayed (the indicator is not visible); when communication is ongoing the ring is visible.
4. "Communication ongoing" means a prompt has been sent and the response (including streamed content and tool-call turns) is not yet complete.
5. The indicator state is per chat and must be updated on the JavaFX Application Thread.
6. Hiding the indicator should not shift the label unexpectedly (e.g. it is neither managed nor visible while idle, or its space is reserved consistently).

### Acceptance Criteria

```gherkin
Scenario: Idle chat shows no indicator
  Given a chat tab is open and no communication is ongoing
  When I look at the tab title
  Then no progress indicator is displayed
  And the title shows only its usual content

Scenario: Ring appears while communication is ongoing
  Given a chat tab is open
  When I send a prompt and the response is in progress
  Then an indeterminate circular progress ring is displayed to the left of the chat label

Scenario: Ring disappears when communication completes
  Given the ring is displayed in a chat tab title
  When the response is complete
  Then the ring is no longer displayed

Scenario: Ring disappears when communication fails
  Given the ring is displayed in a chat tab title
  When the communication ends with an error
  Then the ring is no longer displayed

Scenario: Indicator is per chat
  Given two chat tabs are open
  When communication is ongoing only in the first chat
  Then the ring is displayed only in the first chat's tab title
  And it remains visible when the second tab is selected
```
