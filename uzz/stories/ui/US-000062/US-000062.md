## US-000062 — Confirm and Forget a Chat

### User Story

```
AS A User
I WANT to close and forget a chat after confirming its permanent deletion
SO THAT I can completely discard a conversation I no longer need
```

#### Status
WIP

#### Dependencies
- US-000061

#### Technical Context & Constraints
* **Target System**: Standalone ViberFX desktop application
* **Toolchain / Rules**: Java 21, JavaFX 23.0.2, CommonsFX, AtlantaFX, and Maven; use FXML where practical and follow `uzz/project/coding_standard.md` and `uzz/project/development_framework.md`

#### Notes
1. Provide a small forget icon button in each chat tab title, separate from the archive button, using the existing AtlantaFX framework and icon set.
2. The confirmation must warn that the conversation will be completely discarded.
3. Declining or dismissing the confirmation leaves the tab and conversation unchanged.
4. On confirmation, remove an unarchived conversation from memory or a previously archived conversation from persistent storage, then close its tab.
5. Do not add an interface to discover or resume archived conversations.

### Acceptance Criteria

```gherkin
Scenario: Forget action is available on each chat tab
  Given the ViberFX application has multiple open chat tabs
  When I inspect the tab titles
  Then each tab title has a separate icon button to close and forget that chat

Scenario: Forget action warns before discarding
  Given a chat tab is open
  When I activate its forget button
  Then a confirmation warns that the conversation will be completely discarded
  And the conversation remains available while the confirmation is pending

Scenario: Declining the forget confirmation preserves the chat
  Given the forget confirmation is displayed for an open chat
  When I decline or dismiss the confirmation
  Then the confirmation closes
  And the chat tab remains open
  And the conversation remains unchanged

Scenario: Confirming forget discards an unarchived conversation
  Given an open chat has not been archived
  When I confirm the forget action
  Then its tab closes
  And the conversation is removed from memory
  And other open chat tabs remain open

Scenario: Confirming forget discards a previously archived conversation
  Given an open chat represents a previously archived conversation
  When I confirm the forget action
  Then its tab closes
  And the conversation is removed from persistent storage
```
