## US-000019 — GUI Prompt Input Area

### User Story

```
AS A user
I WANT a text input area in the GUI to type and send prompts
SO THAT I can interact with the conversation through the GUI instead of the command line
```

#### Status
DONE

#### Dependencies
- US-000018

#### Technical Context & Constraints
* **Target System**: Standalone JavaFX desktop application
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `project/development-framework.md`; FXML descriptors whenever possible; UI construction separate from business logic per `project/coding-standard.md`
* **Actor**: Defaults to `FXActor` for this story; actor switching is covered in `US-000021`
* **Phase**: MVP

#### Notes
See `notes.md`

### Acceptance Criteria

```gherkin
Scenario: Input area is visible in the main window
  Given the ViberFX standalone application is running
  When I inspect the main window
  Then a text input field is visible below the conversation view

Scenario: User sends a prompt via the GUI input area
  Given the ViberFX standalone application is running
  And the input area contains "hello world"
  When the user clicks the Send button
  Then a PromptMessage with text "hello world" is added to the current Chat
  And the conversation view updates to show the new message

Scenario: Send via Enter key
  Given the ViberFX standalone application is running
  And the input area contains "hello world"
  When the user presses Enter
  Then a PromptMessage with text "hello world" is added to the current Chat
  And the conversation view updates to show the new message

Scenario: Empty input does not create a message
  Given the ViberFX standalone application is running
  And the input area is empty
  When the user clicks the Send button
  Then no message is created
  And the conversation remains unchanged

Scenario: Input area is cleared after sending
  Given the ViberFX standalone application is running
  And the input area contains "hello world"
  When the user clicks the Send button
  Then the input area is cleared
```
