## US-000015 — CLI-triggered JavaFX Conversation Rendering

### User Story

```
AS A user
I WANT to render a conversation in a JavaFX window via a command-line option
SO THAT I can view the conversation with styled UI during a CLI session
```

#### Status
DONE

#### Dependencies
- US-000006
- US-000014

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application / CLI hybrid
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `project/development-framework.md`; FXML descriptors whenever possible; UI rendering logic follows `project/coding-standard.md`
* **AtlantaFX user agent**: The JavaFX window shall apply AtlantaFX's styles as the user agent stylesheet via `Application.setUserAgentStylesheet(...)` before any scene is shown
* **Phase**: MVP

#### Notes
See `notes.md`

### Acceptance Criteria

```gherkin
Scenario: User starts CLI with --fx-render
  Given ViberCLI is started with the --fx-render flag
  When the conversation is rendered
  Then a JavaFX window opens showing the conversation
  And the window applies AtlantaFX styles as the user agent stylesheet

Scenario: Conversation updates are reflected in the JavaFX window
  Given the --fx-render window is open
  When new messages are added to the conversation
  Then the JavaFX window updates to show the new messages

Scenario: CLI and FX window run concurrently
  Given ViberCLI is started with --fx-render
  When the user interacts with the CLI
  Then the CLI remains responsive
  And the JavaFX window remains open and responsive

Scenario: AtlantaFX stylesheet is applied before scene creation
  Given the --fx-render flag is provided
  When the JavaFX window is created
  Then Application.setUserAgentStylesheet is called with an AtlantaFX stylesheet
  And the stylesheet is set before any Scene is instantiated
```
