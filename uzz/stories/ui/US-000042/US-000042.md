## UI/US-000042 — Scroll Chat Content with the Mouse Wheel

### User Story

```
AS A user
I WANT to scroll chat and message content with the mouse wheel
SO THAT I can navigate the conversation without operating scroll bars
```

#### Status
DONE

#### Dependencies
- UI/US-000014

#### Technical Context & Constraints
* **Target System**: Shared JavaFX conversation renderer used by the standalone application and embeddable component
* **Toolchain / Rules**: JavaFX per `project/development-framework.md`; UI construction separate from business logic per `project/coding-standard.md`

#### Notes
Mouse-wheel handling applies over the chat without requiring pointer interaction with a scrollbar. Horizontal wheel input scrolls horizontally only when the hovered chat or message content has horizontal overflow.

### Acceptance Criteria

```gherkin
Scenario: Wheel input scrolls the chat
  Given the pointer is over the chat
  And the chat can scroll in the wheel direction
  When the user uses the mouse wheel
  Then the chat content scrolls in that direction

Scenario: Wheel input scrolls nested message content first
  Given the pointer is over scrollable content inside a message
  And that content can scroll in the wheel direction
  When the user uses the mouse wheel
  Then the message content scrolls in that direction
  And the outer chat does not scroll during that wheel event

Scenario: A later wheel event scrolls the outer chat after nested content reaches its limit
  Given the pointer is over scrollable content inside a message
  And a previous wheel event scrolled that content to its limit without scrolling the outer chat
  And the outer chat can scroll in that direction
  When the user uses the mouse wheel
  Then the outer chat scrolls in that direction

Scenario: Horizontal wheel input scrolls only when horizontal overflow exists
  Given the pointer is over chat or scrollable message content
  When the user uses horizontal wheel input
  Then content scrolls horizontally if it has horizontal overflow
  And vertical scrolling is not substituted when horizontal scrolling is unavailable
```
