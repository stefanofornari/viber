## UI/US-000043 — Scroll Focused Chat Content with the Keyboard

### User Story

```
AS A user
I WANT to scroll the focused chat element with the keyboard
SO THAT I can navigate conversation content without using a mouse
```

#### Technical Context & Constraints
* **Target System**: Shared JavaFX conversation renderer used by the standalone application and embeddable component
* **Toolchain / Rules**: JavaFX per `project/development-framework.md`; UI construction separate from business logic per `project/coding-standard.md`

### Acceptance Criteria

```gherkin
Scenario: Arrow keys scroll the focused element
  Given a scrollable element in the chat has keyboard focus
  And it can scroll in the direction of the pressed arrow key
  When the user presses that arrow key
  Then the focused element scrolls in that direction

Scenario: Page Up and Page Down scroll the focused element
  Given a scrollable element in the chat has keyboard focus
  And it can scroll vertically
  When the user presses Page Up or Page Down
  Then the focused element scrolls vertically in the corresponding direction

Scenario: Keyboard input does not scroll an element at its limit
  Given a scrollable element in the chat has keyboard focus
  And it is at its limit in the direction of the pressed key
  When the user presses an arrow key or Page Up or Page Down
  Then that element does not scroll beyond its limit
```
