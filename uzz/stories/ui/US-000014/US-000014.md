## US-000014 — JavaFX Conversation Output Rendering

### User Story

```
AS A user
I WANT to view a conversation in a JavaFX window
SO THAT I can read it and interact with it in a user friendly manner
```

#### Status
DONE

#### Dependencies
- US-000001

#### Technical Context & Constraints
* **Target System**: JavaFX desktop application
* **Toolchain / Rules**: JavaFX, CommonsFX, AtlantaFX per `project/development-framework.md`; FXML descriptors whenever possible; UI rendering logic follows `project/coding-standard.md`
* **AtlantaFX styles**: Use AtlantaFX styles
* **Phase**: MVP

#### Notes
See `notes.md`

### Acceptance Criteria

```gherkin
Scenario: A user views a Conversation with one Chat in a JavaFX window
  Given a Conversation containing one Chat with two Messages
  When the user views the Conversation in a JavaFX window
  Then the window displays both Messages in order
  And the conversation is visually readable

Scenario: A user views a Conversation with multiple Chats in a JavaFX window
  Given a Conversation containing two Chats
  When the user views the Conversation in a JavaFX window
  Then the Chats are visually separated in the window
  And Messages within each Chat appear in order

Scenario: Different Message types appear distinct to the user in a JavaFX window
  Given a Conversation containing Messages of type prompt, reply, and thought
  When the user views the Conversation in a JavaFX window
  Then each Message type is visually distinguishable

Scenario: A user views an empty Conversation in a JavaFX window
  Given a Conversation with no Chats
  When the user views the Conversation in a JavaFX window
  Then the window displays an appropriate empty state
```
