## US-000025 — CLI Human-in-the-Middle Confirmation

### User Story

```
AS A User
I WANT the CLI to prompt me for confirmation before executing READWRITE or UNKNOWN tools when in INTERACTIVE mode
SO THAT I can review and approve potentially destructive filesystem operations
```

### Acceptance Criteria

```gherkin
Scenario: INTERACTIVE mode prompts for READWRITE tool approval in CLI
  Given the application is running in CLI mode
  And InteractionMode is INTERACTIVE
  When the LLM invokes a READWRITE tool
  Then the CLI displays the tool name and arguments
  And prompts the user to approve or deny execution

Scenario: User approves READWRITE tool execution in CLI
  Given the CLI is prompting for READWRITE tool approval
  When the user enters "yes" or "y"
  Then the tool is executed
  And the result is returned to the LLM

Scenario: User denies READWRITE tool execution in CLI
  Given the CLI is prompting for READWRITE tool approval
  When the user enters "no" or "n"
  Then the tool is not executed
  And a denial message is returned to the LLM

Scenario: ASK mode blocks tool execution in CLI
  Given the application is running in CLI mode
  And InteractionMode is ASK
  When the LLM invokes any tool
  Then no tool is executed
  And a message indicating tools are disabled is returned

Scenario: AGENT mode executes tools without confirmation in CLI
  Given the application is running in CLI mode
  And InteractionMode is AGENT
  When the LLM invokes any tool
  Then the tool executes immediately without prompting

Scenario: READONLY tools execute without confirmation in INTERACTIVE mode
  Given the application is running in CLI mode
  And InteractionMode is INTERACTIVE
  When the LLM invokes a READONLY tool
  Then the tool executes immediately without prompting
```
